# SYLOGOS

Εφαρμογή διαχείρισης και παρακολούθησης μελών του Συλλόγου Τριτέκνων Ν. Έβρου.

## Έκδοση

- **Έκδοση**: 1.0.0
- Ημερομηνία (build) 04 Αυγούστου 2025

## Λειτουργίες

- Διαχείριση μελών
- Διαχείριση τέκων
- Διαχείριση συνδρομών
- Αναζήτηση δεδομένων
- Εξαγωγή δεδομένων σε Excel
- Δημιουργία λοταρίας βάση κριτηρίων και εξαγωγή αποτελεσμάτων

## Απαιτήσεις Συστήματος

-  Windows 11, συμπεριλαμβανομένων 24H2, 23H2, and 22H2 (Enterprise και Education)
-  Windows 10 έκδοση 22H2 και νεότερες
- Αρχιτεκτονική: x64 ή x86

## Τεχνικά Χαρακτηριστικά

- Γλώσσα προγραμματισμού: C#
- Περιβάλον .NET 9
- Βιβλιοθήκες:
  - Entity Framework Core
  - WinForms
